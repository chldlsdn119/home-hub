우리집 허브 내려받기

노트9에서 이 페이지를 열고 아래 버튼을 누르세요.

파일로 내려받기

허브 화면 파일(home-hub.html) 하나가 노트9의 다운로드 폴더에 저장돼요.

허브 파일 내려받기

내려받은 파일 여는 방법

  1. Fully Kiosk Browser를 Play 스토어에서 설치해요.
  2. 설정 → Web Content Settings → Start URL에 file:///sdcard/Download/home-hub.html 를 넣어요.
  3. 파일·저장공간 권한을 허용하면 전체 화면으로 허브가 떠요.

더 간단한 방법: 바로 열기

파일 없이 주소로 열어도 똑같이 작동하고, 화면을 고칠 때마다 자동으로 최신 버전이 돼요.
